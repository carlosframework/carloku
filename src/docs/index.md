# Documentation

Carloku is the hosted CARLOS platform. You deploy a binary, get a URL, and
the platform handles certificates, restarts, and putting a quiet app to
sleep until traffic comes back.

These pages cover running your app day-to-day, and the account settings
that go with it.

Haven't deployed yet? [Get started](/get-started/) is where to begin.

Platform internals, self-hosting, and the full `carlos` CLI reference live
at [carlosframework.com/docs](https://carlosframework.com/docs).
